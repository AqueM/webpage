Accessibility notice

This entire website should work correctly with Reader Mode across all browsers. If you find it hard to read or would like to use a screen-reader, try pressing F9. If that doesn't work, the page simply has too little text for it to be eligible.

In that case, I suggest using the "Complexity" toggle in top right to turn off most of the visual flair and noise.

While you're there, check out the other toggles, they may make your stay here more enjoyable.

The page starts in dark mode if your system preference is such. To view it in color, use the black toggle in top right.

These accessibility toggles in top right require javascript to work. To account for it malfunctioning, the site starts without flair and in system font, and onlye nables it on-load.
