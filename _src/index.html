Accesibility notice

This entire website should work correctly with Reader Mode across all browsers. If you find it hard to read or would like to use a screen-reader, try pressing F9. If that doesn't work, the page simply has too little text for it to be eligible.

In that case, I suggest using the "Reduce visual complexity" toggle in top right (3rd from left, 1st green one) to turn off most of the visual flair and noise.

The page starts in dark mode if your system preference is such. To view it in color, use the black toggle in top right.

These accessibility toggles in top right require javascript to work.
